# Sample inputs

Small media kept with the repo so the Phase 7 validation is reproducible
without reaching outside the checkout.

- `hgf_scene.webm` — a 96.7 s slice of *His Girl Friday* (public domain),
  658x480 VP9 video with 48 kHz stereo Opus audio. Source for the real-sample
  tests and the `hgf_scene-*` job.
- `hgf_h264.mp4` — the same scene re-encoded to H.264 + AAC, used to check that
  the mux keeps an MP4 an MP4.

These are public-domain test material, not production content.
